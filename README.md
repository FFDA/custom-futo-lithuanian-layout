YAML failas, kurį galima naudoti FUTO klaviatūroje, gauti qwerty išdėstymą, kuris viršutinėje eilutėje turi visas lietuviškas raides. Apačioje: kablelį, tašką ir klaustuką.

Visa kitą nesiskiria nuo standartiško klaviatūros.

Nuotraukoje matoma skaičių eilutė yra įjungiama nustatymuose.

Instrukcija kaip įsikelti layout'ą: https://docs.keyboard.futo.org/settings/customlayouts#going-to-custom-layouts-menu
